#Daily

Morning (Everyone):

# 1. Get fresh dev
git checkout dev && git pull

# 2. Update your branch
git checkout your-name
git merge dev


During Work:(optional)
# Small, frequent commits(not needed but if you want you can do this)
git add .
git commit -m "Feature: [what you did]"
git push


EOD Merge:
# Complete EOD sequence

#first check which branch you are using 
git branch


#pushing to your remote repo from local repo
git checkout your-name
git add . && git commit -m "EOD"
git push

#this is developer branch first pulling to get latest changes from remote dev to local dev repo or folder
git checkout dev
git pull (always pull from merging)

#thn merging your repo to dev
git merge your-name
git push

#at last go to your branch and merge dev to finally fetch latest update you updated or some one updated
git checkout your-name
git merge dev
git push




When conflicts happen during EOD merge:
bash
# 1. Check which files have conflicts
git status

# 2. Open each file, look for:
# <<<<<<< HEAD (dev changes)
# ======= (your changes)
# >>>>>>> your-name

# 3. Edit files to keep correct code
# 4. Mark as resolved:
git add filename.java(example change file name as it is)

# 5. Complete the merge:
git commit -m "Resolved merge: your-name → dev"

# 6. Continue with push
git push origin dev
